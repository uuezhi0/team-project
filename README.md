## User Stories
### User Story 1
“As a player, I want to progress through dialogue and story scenes so I can progress through the narrative and learn about the characters.”
### User Story 2
“As a player, I want to make dialogue choices that influence character relationships and story outcomes (player decisions have meaningful outcomes).”
### User Story 3
“As a player, I want to view character profiles and affection levels so I can learn more about each character and track my relationship progression towards a "win" state.”
### User Story 4
“As a player, I want to save and load my game progress so I can continue playing without having to restart the story.”
### User Story 5
“As a player, I want to do trivia quizzes in conversations with characters so I can earn affection points and unlock interactions (and “win” a character’s ending).”

### Use Case 2: Browse by Call number
**Lead:** TODO

**Main Flow:** 
1. Student enters a call number (PS3537)
2. System shows the Robarts books shelved at and around that call number, in shelf order
3. Student can move to earlier or later on the shelf. 

**Alternative Flows:**
- Call number isn't valid -> System says so and shows an example
- Nothing is shelved there -> System shows the nearest books before and after

### Use Case 3: Find it in Robarts
**Lead:** TODO

**Main flow:**
1. Student selects a book from search and browse results
2. System looks up the book's call number in the Robarts floor table
3. System shows the floor and stacks area where the book is shelved

**Alternative flows:**
- Call number isn't in the floor table → System says the location is unknown and suggests asking at the service desk.
- Call number isn't Library of Congress (e.g. Dewey) → System says it can't place that call number.
